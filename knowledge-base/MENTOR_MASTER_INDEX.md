## 🧠 MEMORY TRICK MASTER LIST

### Physics:
- **RED CAT AN OX** = Reduction at Cathode, Anode is Oxidation
- **Snell's Law:** "n₁ sin = n₂ sin" — same product on both sides
- **Lenz's Law:** Induced current OPPoses change in flux

### Chemistry:
- **Cannizzaro = CANNOT have α-H**
- **Clemmensen = aCidic (both start with C)**
- **Wolf-Kishner = Basic (W comes after C — Stronger)**
- **Fehling's: Benzaldehyde Fools Nobody** (doesn't give positive result)
- **2,4-DNP = D Notices C=O** (both aldehydes AND ketones)
- **FAKE = First order: A(freq), K(rate constant), E(activation energy)**

### Mathematics:
- **ILATE** = Integration by Parts priority: Inverse trig, Log, Algebraic, Trig, Exponential
- **π/2 pairs:** sin⁻¹x + cos⁻¹x = π/2; tan⁻¹x + cot⁻¹x = π/2
- **|adj A| = |A|^(n-1)** — subtract 1 from order for exponent

### Computer Science:
