## 📚 CHAPTER REFERENCE

### 📘 CH 2: SOLUTIONS | 5–8 marks | 🟡 HIGH

**Key Concepts:**
1. Molarity (M) = mol/L — changes with temperature
2. Molality (m) = mol/kg(solvent) — independent of temperature
3. Henry's Law: p = KH × x (gas solubility ↑ with pressure; ↓ with temperature)
4. Raoult's Law: pA = pA° × xA; pTotal = pA°xA + pB°xB
5. Colligative properties (depend on number of particles, NOT nature):
   - Relative lowering of VP: (p°–p)/p° = xB
   - Elevation in BP: ΔTb = Kb × m × i
   - Depression in FP: ΔTf = Kf × m × i  (Kf water = 1.86, Kb water = 0.512)
   - Osmotic pressure: π = iCRT
6. Van't Hoff factor: i = 1 + (n–1)α (dissociation); i < 1 (association)

**KEY NUMERICAL (appears almost every year as MCQ):**
70g solute (MW=70) in 700g solvent, density = 1.5 g/mL → molality:molarity = **1.4**
(Moles=1; molality=1/0.7=1.43 m; Volume=(770/1.5)mL; molarity=1/(770/1500)=1.948 M; ratio=1.4)

**Assertion traps:** Molarity changes with T (TRUE); molality does NOT (TRUE) — often tested

### 📘 CH 3: ELECTROCHEMISTRY | 8–11 marks | 🔴 MUST

**Key Concepts:**
1. EMF: E°cell = E°cathode – E°anode (reduction potentials)
2. Nernst Equation (298K): E = E° – (0.0592/n) log Q
3. ΔG° = –nFE°cell = –RT lnK  [F = 96500 C/mol]
4. Molar conductance: Λm = (κ × 1000) / M (S cm² mol⁻¹)
5. Kohlrausch's Law: Λ°m = ν₊λ°₊ + ν₋λ°₋
6. Degree of dissociation: α = Λm / Λ°m
7. Faraday's 1st Law: m = (M × I × t) / (n × F)
8. Batteries: Primary (dry cell, button) = NOT rechargeable; Secondary (Lead, Li-ion) = rechargeable
9. RED CAT, AN OX: Reduction at Cathode; Oxidation at Anode

**KEY NUMERICALS:**
- Nernst: Ni(s)+Cu²⁺→Ni²⁺+Cu(s); E°=0.62V; find E at [Cu²⁺]=0.1M, [Ni²⁺]=1M
  → E = 0.62 – (0.0592/2)log(1/0.1) = 0.62 – 0.0296 = **0.5904V**
- Faraday: mass of Ag at 1A for 1 hour = (108×1×3600)/(1×96500) = **4.03g**
- Kohlrausch: Λ°m(CH₃COOH) = Λ°m(HCl) + Λ°m(CH₃COONa) – Λ°m(NaCl)

**Assertion trap (SQP):** "Secondary cells used in inverters. R: Primary cells can be recharged" → A true, **R FALSE**

### 📘 CH 4: CHEMICAL KINETICS | 6–8 marks | 🔴 MUST

**Key Concepts:**
1. Rate law: rate = k[A]ˣ[B]ʸ (determined experimentally, not from equation)
2. Zero order: [R]=[R]₀–kt; t½=[R]₀/2k (depends on initial conc)
3. First order: ln[R]=ln[R]₀–kt; t½=0.693/k (**independent of initial conc**)
4. Units: zero order → mol L⁻¹ s⁻¹; first order → s⁻¹
5. Arrhenius: k = Ae^(–Ea/RT); log(k₂/k₁) = (Ea/2.303R)(1/T₁ – 1/T₂)
6. Catalyst: lowers Ea, does NOT change ΔH

**KEY NUMERICAL (every single exam):**
Rate triples (k₂/k₁=3) from 298K to 318K; R=8.314, log3=0.4771
→ 0.4771 = Ea/(2.303×8.314) × (20/(298×318)) → **Ea ≈ 43.5 kJ/mol**

**Assertion trap:** "t½ of zero order is independent of initial concentration" → **FALSE** (it equals [R]₀/2k)

### 📘 CH 6: HALOALKANES & HALOARENES | 4–6 marks | 🟡 HIGH

**Key Concepts:**
1. SN1: carbocation intermediate; racemization; tertiary favoured; polar protic solvent
2. SN2: backside attack; inversion (Walden); primary favoured; polar aprotic solvent
3. Haloarenes: –X is o/p director but deactivating; less reactive than alkyl halides

**Named Reactions:**
- Finkelstein: RX + NaI/acetone → RI
- Swarts: RF synthesis using SbF₃/HgF₂
- Wurtz: 2RX + 2Na → R–R + 2NaX

**Conversions (Section B):**
- Chlorophenylmethane → 2-phenyl-ethanamine: KCN then LiAlH₄
- Nitrobenzene → 4-bromoaniline: Reduce → Acetylate → Brominate → Deacetylate

### 📘 CH 7: ALCOHOLS, PHENOLS & ETHERS | 3–5 marks | 🟡 MEDIUM

**Key Concepts:**
1. Acidity: Phenol > H₂O > Alcohol (phenol resonance stabilises phenoxide)
2. FeCl₃ test: phenol → violet colour
3. Lucas test: tertiary (immediate turbidity) > secondary (slow) > primary (no reaction at RT)
4. o-Cresol: –OH on **sp² hybridised** carbon (aromatic — SQP MCQ every year!)
5. Ethers MORE volatile than alcohol of same MW (no H-bonding between ether molecules)

### 📘 CH 8: ALDEHYDES, KETONES & CARBOXYLIC ACIDS | 8–10 marks | 🔴 MUST

**Identification Tests:**
| Test | Positive Result | Given by |
|------|----------------|----------|
| 2,4-DNP | Orange/yellow ppt | Aldehydes AND ketones (C=O) |
| Tollen's test | Silver mirror | Aldehydes ONLY |
| Fehling's test | Brick red ppt | Aliphatic aldehydes ONLY (NOT benzaldehyde, NOT ketones) |
| Iodoform test | CHI₃ yellow ppt | CH₃CO– group; CH₃CHO; CH₃CHOH– |

**CRITICAL TRAP: Fehling's NOT given by benzaldehyde** (appears 4/6 SQPs as trap)

**Named Reactions (MUST KNOW — appear every year):**
| Reaction | Condition | What it does |
|----------|-----------|-------------|
| Cannizzaro | Conc. NaOH, no α-H | Self-oxidation-reduction of aldehyde |
| Aldol condensation | Dil. NaOH, has α-H | β-hydroxy aldehyde → dehydration → α,β-unsat. aldehyde |
| Clemmensen reduction | Zn-Hg/HCl (ACIDIC) | C=O → CH₂ |
| Wolf-Kishner reduction | NH₂NH₂/KOH (BASIC) | C=O → CH₂ |
| Rosenmund | H₂/Pd-BaSO₄ | Acid chloride → Aldehyde |
| HVZ reaction | Cl₂/Br₂ + Red P | α-halogenation of carboxylic acid |

**Memory Tricks:**
- Cannizzaro = "CANNOT have α-H"
- Clemmensen = acidic (C=Clemmensen, C=aCid — both C)
- Wolf-Kishner = basic (W comes after C alphabetically, just as Basic is "stronger")
- Fehling's: "Benzaldehyde Fools Nobody" — does NOT give positive Fehling's

**Carboxylic Acids:**
- Acidity: EWG increases acidity; EDG decreases acidity
- Decarboxylation: RCOONa + NaOH/CaO → RH + Na₂CO₃

### 📘 CH 9 (INORGANIC): COORDINATION COMPOUNDS | 6–9 marks | 🔴 MUST

**IUPAC Naming Rules:**
1. Cation first, then anion
2. Ligands in alphabetical order; prefix (di/tri) NOT counted for alphabetical
3. Anionic ligands → -o suffix (chlorido, nitrito); neutral → as is (ammine, aqua, carbonyl)
4. Metal oxidation state in Roman numerals (in brackets)
5. If complex anion → metal name + -ate (e.g., ferrate, argentate, cuprate)

**MUST-KNOW Formulas (Section B every year):**
- diaquasilver(I) dichloridoargentate(I) → **[Ag(H₂O)₂][AgCl₂]**
- dihydroxidobis(triphenylphosphine)nickel(II) → **[Ni(OH)₂(PPh₃)₂]**
- tetraamminecopper(II) sulphate → **[Cu(NH₃)₄]SO₄**

**Key Concepts:**
1. EDTA is **hexadentate** (6 donor atoms)
2. Spectrochemical series (weak → strong field): I⁻ < Br⁻ < Cl⁻ < F⁻ < OH⁻ < H₂O < en < NO₂⁻ < CN⁻ < CO
3. Strong field ligands → pairing → low spin → fewer unpaired electrons
4. Colour due to d-d transitions (requires partially filled d-orbitals)
5. Magnetic moment = √n(n+2) BM (n = unpaired electrons)

**VBT Hybridizations:**
- d²sp³ = inner d, octahedral (strong field)
- sp³d² = outer d, octahedral (weak field)
- dsp² = square planar (Pt, Pd, Ni with strong field)
- sp³ = tetrahedral

### 📘 CH 8 (INORGANIC): d- AND f-BLOCK ELEMENTS | 4–7 marks | 🔴 HIGH

**Why Transition Metals are Special:**
- Variable OS (small energy gap between (n-1)d and ns)
- Coloured ions (d-d transitions)
- Catalytic activity (variable OS + complex formation)
- Magnetic properties (unpaired d electrons)
- Zn, Cd, Hg: NOT transition metals (d¹⁰ in all OS)

**KMnO₄ reactions:**
- Acidic medium: MnO₄⁻ → Mn²⁺ (colourless); 5e⁻ change
- Alkaline medium: MnO₄⁻ → MnO₂ (brown); 3e⁻ change
- Preparation: MnO₂ → fuse with KOH/KNO₃ → K₂MnO₄ (green) → Cl₂ → KMnO₄ (purple)

**K₂Cr₂O₇:**
- Cr₂O₇²⁻ (orange, acidic) ⇌ 2CrO₄²⁻ (yellow, basic)
- Strong oxidising agent; 6e⁻ change per Cr

**Lanthanoids vs Actinoids:**
- Both = inner transition metals
- Lanthanoids: 4f filling; mainly +3 OS; not radioactive
- Actinoids: 5f filling; variable OS (+3 to +7); ALL radioactive

### 📘 CH 13: AMINES | 5–7 marks | 🔴 HIGH

**Basicity Order (aqueous):** Aliphatic: 2° > 1° > 3° > NH₃ >> Aniline
(3° less basic in water due to steric hindrance preventing hydration)

**Hinsberg's Test:**
- 1° amine + C₆H₅SO₂Cl → sulphonamide soluble in NaOH
- 2° amine + C₆H₅SO₂Cl → sulphonamide **insoluble** in NaOH
- 3° amine → **no reaction**

**Diazonium Salts:**
- Formed: 1° aromatic amine + NaNO₂ + HCl at 0–5°C (unstable above)
- Sandmeyer: diazonium + CuCl → ArCl; CuBr → ArBr; CuCN → ArCN
- Balz-Schiemann: diazonium + HBF₄ → ArF
- Coupling: diazonium + phenol/aniline → azo dye (orange)

**SQP MCQ Trap:** A, B, C are amines equal MW; A & B react with C₆H₅SO₂Cl, B's ppt insoluble in NaOH
→ A=1°, B=2°, C=3° → BP order: A > B > C

## 🎓 ANSWER WRITING TIPS

### Organic Chemistry:
1. Always write **balanced equations** with conditions above/below arrow
2. For mechanism: show curved arrows for electron movement
3. For "distinguish between" questions: use two separate reactions/tests
4. For conversions: number each step clearly

### Physical Chemistry Numericals:
- **Given → Formula → Substitution → Answer with units** (every step = marks)
- Write R = 8.314 J/mol/K when using Arrhenius
- Always write Faraday's constant as 96500 C/mol

### Inorganic Chemistry:
- For coordination compounds: write correct formula with square brackets
- For d-block: state electronic configuration to justify answer
- For Assertion-Reason: check both A and R independently before checking if R explains A
