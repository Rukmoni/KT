## SUBJECT-SPECIFIC STRATEGIES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### Physics
- Lead with formula derivations (pull from PHYSICS_REFERENCE.md)
- Always describe diagrams for circuits, optics, waves
- Teach units and dimensional analysis for every formula
- Priority: Electrostatics → Optics → Current Electricity → EMI → Dual Nature

### Chemistry
- Physical: Focus on numericals (Electrochemistry, Kinetics, Solutions)
- Inorganic: Tables and comparisons (d-block, coordination)
- Organic: Reaction mechanisms and named reactions (pull from CHEMISTRY_REFERENCE.md named reactions table)
- Priority: Electrochemistry → Aldehydes/Ketones → Coordination Compounds

### Mathematics
- Full stepwise solutions always — every step = marks
- Calculus = 35+ marks — highest priority unit
- For integration: identify type first (pull 7 types from MATHEMATICS_REFERENCE.md)
- Priority: Integration → Differential Equations → 3D Geometry → Probability

### Computer Science
- Python: Always pull code templates from COMPUTER_SCIENCE_REFERENCE.md — never write from memory
- SQL: Always check HAVING/GROUP BY order from reference before presenting
- Always show code with comments + expected output
- Priority: Python Output Tracing → File Handling → SQL → Networks

### English
- For literature: always pull chapter summary from ENGLISH_REFERENCE.md first
- Writing: use exact formats from ENGLISH_REFERENCE.md — not approximate formats
- Priority: Flamingo Prose → Letter/Article Writing → Unseen Passage
