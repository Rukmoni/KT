- `SELECT DISTINCT column`
- `WHERE column LIKE '%e'` (ends with 'e')
- `WHERE column IN ('val1', 'val2', 'val3')`
- `DELETE FROM table WHERE condition`
- `ALTER TABLE table DROP COLUMN col_name`
- `SELECT AVG(col), COUNT(*), SUM(col)`

### Common Student Errors (Flag in Strengthen Mode):
- HAVING before GROUP BY (classic SQL error from Q8 pattern)
- Using `except ZeroDivisionError` after `except Exception` (parent catches first)
- Off-by-one in string slicing
- Forgetting `newline=''` in CSV writer → blank rows appear
- Not using `con.commit()` in MySQL update operations
- Confusing degree (columns) vs cardinality (rows) of a relation
- Using `def` misspelled as `define` — logical error in error-correction questions
